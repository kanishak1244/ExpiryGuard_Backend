Technical Architecture

How We Built Dawaiflow

Built with high-performance, proven technologies designed for low latency, offline resiliency, and hardware compatibility.

FRONTEND & POS

Web & Mobile

• Web: Native ES6, CSS3, Inter + JetBrains Mono (Zero bloated JS dependencies).
• Mobile: Flutter (Dart) Android companion app for counter camera billing.

BACKEND & API

FastAPI & Python

• Python 3.11 with FastAPI.
• Asynchronous REST API + real-time WebSockets for sub-100ms hardware event streaming.
• Background workers for scheduled alerts.

DATA ENGINE

Postgres + 240k Master

• PostgreSQL with SQLAlchemy.
• Pre-indexed Indian Medicine Catalog of 240,000+ medicines with composition & HSN.
• Atomic transactions & soft-delete.

AI & HARDWARE

Vision & Print Agent

• AI: Gemini 3.1 Flash-Lite + PaddleOCR + OpenCV.
• Hardware: Windows Desktop Print Agent piping ESC/POS to 58mm/80mm thermal printers.
